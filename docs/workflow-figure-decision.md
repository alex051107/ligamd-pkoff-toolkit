# Workflow figure decision

The repository landing page now includes one editable SVG overview of the
public route. It answers a first reader's four questions in order:

1. what structural and trajectory inputs enter the toolkit;
2. where each of the three replicas is checked and represented separately;
3. where Static20 and averaged Dynamic10 become a feature receipt; and
4. where optional experimental-pKoff prediction begins.

The figure deliberately gives `OUT_OF_SCOPE_NO_PREDICTION` the same visual
status as the successful route. It also states that endpoint-v2 is a geometric
complete-exit rule and not a physical dissociation-rate estimate. No model
artifact, scientific threshold, runtime interface, or public-data boundary is
changed by this documentation-only addition.
